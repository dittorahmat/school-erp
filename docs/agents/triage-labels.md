# Triage Labels

The five canonical triage roles and their corresponding labels in GitHub Issues:

| Role | Label | Purpose |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | Default label for new incoming issues |
| `needs-info` | `needs-info` | Blocked waiting for author or requester clarification |
| `ready-for-agent` | `ready-for-agent` | Specification clear, actionable by autonomous coding agent |
| `ready-for-human` | `ready-for-human` | Requires human decision, architectural alignment, or signoff |
| `wontfix` | `wontfix` | Issue declined or closed as out-of-scope |
